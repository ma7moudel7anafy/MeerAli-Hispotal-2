# خطة تنفيذ تطويرات واجهة الاستقبال والعيادات - مستشفى ميت علي

## 1. رصيد بداية الوردية ومطابقة الخزينة (Opening Shift Cash Float & Drawer Balance)
- [x] **تحديد وحفظ عهدة بداية الوردية:** إمكانية تسجيل مبلغ عهدة الفكة الافتتاحية للصراف مع الملاحظات والمسؤول.
- [x] **معادلة الجرد الفعلي:** حساب `عهدة الفكة الافتتاحية` + `كاش الكشوفات المحصل اليوم` = `إجمالي النقدية المتوقع وجودها بالدرج عند الإقفال`.
- [x] **شاشة إيرادات الخزينة وتقفيل الوردية:** بطاقة عهدة مطابقة بارزة مع إمكانية تعديل رصيد بداية الوردية في أي وقت.
- [x] **تقرير ورقي معتمد لتقفيل الوردية:** شيت طباعة رسمي جاهز يحتوي على بيانات العهدة ومتحصلات الموظفين ومساحات التوقيعات والاعتماد.

## 2. إشعارات الواتساب والطباعة السريعة (WhatsApp Patient Notifications & Quick Thermal Printing)
- [x] **نافذة إرسال رسائل الواتساب (`PatientNotificationModal`):**
  - زر تشغيل الواتساب بنقرة واحدة عبر الرابط المعتمد `https://wa.me/20...`.
  - معالجة وتنسيق أرقام الهواتف المصرية تلقائياً.
  - إمكانية تعديل رقم هاتف المريض قبل الإرسال ومعاينة حية لشكل الرسالة داخل فقاعة واتساب.
  - زر لنسخ نص الرسالة بنقرة واحدة.
- [x] **التبويبات المتاحة للإرسال:**
  1. 🎫 **تذكرة الدور:** اسم المريض، العيادة، الطبيب، رقم الدور، وتوقيت الحضور.
  2. 🧾 **إيصال السداد المالي:** رقم الإيصال المعتمد، المبلغ المسدد، طريقة الدفع، اسم الصراف، والتوقيت.
  3. 💊 **الروشتة الطبية والعلاج:** التشخيص الطبي، قائمة الأدوية بالجرعات، الفحوصات والتحاليل، وتاريخ الاستشارة.
- [x] **الطباعة المباشرة:**
  - 🖨️ كارت الدور الحراري بمقاس 80 مم / 58 مم مع باركود ورقم دور ضخم (`ThermalQueueTicketModal`).
  - 🖨️ إيصال السداد المالي الرسمي.
  - 🖨️ الروشتة الطبية الورقية.

## 3. تصنيف الأولويات والحالات الإنسانية (Priority & Triage Tags)
- [x] **أنواع الأولويات:**
  - 🟢 **عادي (`normal`)**: دور طبيعي.
  - ⚡ **حالة طارئة (`urgent`)**: وميض أحمر وتنبيه بصري، تتقدم فورياً لأول الطابور في عيادة الطبيب.
  - 👵 **كبار السن (`elderly`)**: تمييز الحالات من سن 60 عاماً فما فوق تلقائياً عند التسجيل.
  - ♿ **أصحاب الهمم (`special_needs`)**: أولوية إنسانية مخصصة.
- [x] **شاشة الاستقبال (`VisitsManager`):** أشرطة تصفية بالـ Priority وبطاقات ملونة بوضوح.
- [x] **طابور عيادة الطبيب (`DoctorClinicPortal`):**
  - ترتيب تلقائي يرفع الحالات الطارئة إلى قمة المرضى الحاضرين بالصالة.
  - شارات بصرية واضحة لكل مريض في الطابور.
  - إمكانية مشاركة الروشتة بالواتساب مباشرة بعد إتمام الكشف.
